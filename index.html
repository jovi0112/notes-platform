以后每一讲怎么进这个平台？

办法一（自己就能做）：打开「笔记工坊」

  1. 双击 notes-forge\启动笔记工坊.bat，浏览器会打开一个上传页。
  2. 选课堂笔记 PDF（微信收到的就行），先选科目（数学 / 语文 / 英语），填讲次标题，点「开始生成」。
  3. 等 2~6 分钟，它会自动做完这几件事：把每页转成图、逐页判断这页是封面还是正文还是例题、写一分钟总结和思维导图、整理例题、出雷区和自测、最后直接写进这个平台。
  4. 回来刷新本页，新的一讲就出现了。

办法二（要更精细时）：让阿岩手工整理，流程和下面一样，只是每一页对到哪个模块由人逐页确认。

  1. 同一份 PDF 拆成板书页图（pages/LXX/p01.jpg…），按上课顺序存好。
  2. 在 data/board-map.js 里把每一页对到纪要的位置上：哪个知识模块该嵌第几页、哪道例题该嵌第几页，各写一句"这页是什么"。
  3. 纯封面 / 目录 / 空白页写进 skipInBody，它们只留在文末画廊，不占正文。
  4. 在 data/index.js 的名单里加一行 'lessonXX'，刷新就能看到。

平台是纯静态网页，不依赖服务器：换电脑、换手机，只要这堆文件在，笔记就在。首页按数学 / 语文 / 英语分科排列，每一讲都自带「一分钟总结 + 知识点 + 例题 + 雷区 + 自测 + 复习打卡」。
